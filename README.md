# Phlorest phylogeny derived from Cathcart et al. 2020 'Numeral classifiers and number marking in Indo-Iranian: A phylogenetic approach'

[![CLDF validation](https://github.com/phlorest/cathcart_et_al2020/workflows/CLDF-validation/badge.svg)](https://github.com/phlorest/cathcart_et_al2020/actions?query=workflow%3ACLDF-validation)

## How to cite

If you use these data please cite
- the original source
  > Cathcart, C., Hölzl, A., Jäger, G., Widmer, P., & Bickel, B. (2020). Numeral classifiers and number marking in Indo-Iranian: A phylogenetic approach. Language Dynamics and Change, 11(2), 273-325. https://doi.org/10.1163/22105832-bja10013
- the derived dataset using the DOI of the [particular released version](../../releases/) you were using

## Description

A [Phlorest phylogeny](https://github.com/phlorest) of the Indo-European language family computed from a bayesian analysis scaled by years.


This dataset is licensed under a https://creativecommons.org/licenses/by/4.0/ license

Source available online at 10.1163/22105832-bja10013
